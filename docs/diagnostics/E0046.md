# E0046: `is` on something that is not an object

`is` tests identity, so both sides must be objects: values of a class, or optionals of one. A number, a `bool`, a `string` or an array is not.

## Why

A number, a `string` or an array is a value. Two of them are the same when they are equal, and `==` tests that. Identity only makes a difference between objects.

## Broken

```sisu
fn main() {
    let a = 1
    let b = 1
    print(a is b)
}
```

## Fixed

```sisu
fn main() {
    let a = 1
    let b = 1
    print(a == b)
}
```
