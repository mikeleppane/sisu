# E0064: constructor with more arguments than fields

A constructor names every field of its class once, in declaration order: `Point(x: 1)` for a class with the one field `x`.

## Why

Each argument of a constructor sets one field. An argument after the last field has no field to set.

## Broken

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(x: 1, y: 2)
    print(p.x)
}
```

## Fixed

```sisu
class Point {
    x: i64
    y: i64
}

fn main() {
    let p = Point(x: 1, y: 2)
    print(p.x)
}
```
