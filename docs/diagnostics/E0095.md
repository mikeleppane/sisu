# E0095: `}` in a string

In the text of a string literal a `{` opens an interpolation, and the `}` that matches it closes it. Any other `}` is an error, reported at the `}`. Write `\}` for a literal `}`, as `\{` writes a literal `{`.

## Why

A stray `}` most often means a `{` is missing, and the compiler cannot tell where the interpolation should have started. Escaping both braces keeps the two symmetric. The fix writes `\}`, which is safe: it leaves the text as written.

## Broken

```sisu
fn main() {
    print("a}b")
}
```

## Fixed

```sisu
fn main() {
    print("a\}b")
}
```
