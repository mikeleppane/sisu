# E0021: assignment to something that is not a place

The left side of `=` or of a compound assignment such as `+=` must be a variable, a field, or an element of an array.

## Why

An assignment stores a value in a place. A sum or a call result is a value without a place, so nothing can hold what you assign to it.

## Broken

```sisu
fn main() {
    let mut x = 1
    x + 1 = 3
    print(x)
}
```

## Fixed

```sisu
fn main() {
    let mut x = 1
    x = 3
    print(x)
}
```
