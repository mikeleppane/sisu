# E0102: exponent without digits

The `e` or `E` of a float literal, and its optional sign, is followed by at least one digit: `1e9`, `2e-3` and `1.5E+3`. `1e` and `1e+` are errors.

## Why

An exponent says how far to shift the decimal point, so one without digits says nothing. The compiler does not invent a number to put there, so there is no fix.

## Broken

```sisu
fn main() {
    let x = 1e
    print(x)
}
```

## Fixed

```sisu
fn main() {
    let x = 1e3
    print(x)
}
```
