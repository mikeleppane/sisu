# E0074: assignment to a function

The left side of `=` names a function, not a variable.

## Why

A function's name stands for its code, which does not change while the program runs. Only a variable, a field or an element of an array can take a new value.

## Broken

```sisu
fn one() -> i64 {
    1
}

fn main() {
    one = 2
    print(one())
}
```

## Fixed

```sisu
fn one() -> i64 {
    1
}

fn main() {
    let mut n = one()
    n = 2
    print(n)
}
```
