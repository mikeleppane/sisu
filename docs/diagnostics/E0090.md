# E0090: malformed `\u` escape

`\u` is followed by 1 to 6 hexadecimal digits in braces: `\u{E4}`. A missing brace, no digits, more than 6 digits or a character that is not a hexadecimal digit is an error, reported over the escape as far as it reaches.

## Why

Without the braces, `\uE4` would not say where the number ends. Six digits are enough for every code point, which stops at `10FFFF`.

## Broken

```sisu
fn main() {
    let c = '\uE4'
    print(c)
}
```

## Fixed

```sisu
fn main() {
    let c = '\u{E4}'
    print(c)
}
```
