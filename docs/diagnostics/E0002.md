# E0002: line that starts with a binary `-`

A line that starts with `-` followed by a space is neither a continuation of the line above nor a negation. Sisu rejects it instead of guessing which one you meant.

## Why

A line break ends a statement, so a line that starts with `- x` would begin a new statement that negates `x`. Written with a space after the `-`, it looks like the second half of a subtraction. Sisu reports the line and asks you to say which.

## Broken

```sisu
fn main() {
    let total = 10
    - 3
    print(total)
}
```

## Fixed

```sisu
fn main() {
    let total = 10 -
        3
    print(total)
}
```
