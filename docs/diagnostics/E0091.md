# E0091: escape that is not a Unicode scalar value

`\u{...}` names a Unicode scalar value: a code point from `0` to `10FFFF`, except the surrogates `D800` to `DFFF`. Any other value is an error, reported over the escape.

## Why

A surrogate is half of a pair in UTF-16 and is not a character. A value above `10FFFF` is outside Unicode. Neither can be encoded as UTF-8, which text always is.

## Broken

```sisu
fn main() {
    let c = '\u{D800}'
    print(c)
}
```

## Fixed

```sisu
fn main() {
    let c = '\u{E4}'
    print(c)
}
```
