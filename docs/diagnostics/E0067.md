# E0067: array filled with one object

`[value; n]` makes an array of `n` copies of `value`. When `value` is an object, or an optional of one, every copy is a reference to the same object.

## Why

A change through one element would show in every element, which is almost never what a program means. To give each element an object of its own, start from `None` and fill the array in a loop.

## Broken

```sisu
class Node {
    value: i64
}

fn main() {
    let nodes = [Node(value: 0); 3]
    print(nodes.len())
}
```

## Fixed

```sisu
class Node {
    value: i64
}

fn main() {
    let mut nodes: [Node?] = [None; 3]
    for i in 0..3 {
        nodes[i] = Node(value: i)
    }
    print(nodes.len())
}
```
