# E0133: arm split across lines

A line in a `match` that starts with `|`, `=>` or a guard's `if` continues the arm on the line above. An arm is written on one line.

## Why

A line break ends an arm, as it ends a statement, so the next line is never read as part of the arm above: `| B` on a line of its own would otherwise look like an arm that starts with `|`. The safe fix joins the line to the one above. When a comment lies between them, joining would put the rest of the arm inside the comment, so the report has no fix.

## Broken

```sisu
enum Light {
    Red
    Amber
    Green
}

fn stop(l: Light) -> bool {
    match l {
        Red
        | Amber => true
        Green => false
    }
}

fn main() {
    print(stop(Light.Amber))
}
```

## Fixed

```sisu
enum Light {
    Red
    Amber
    Green
}

fn stop(l: Light) -> bool {
    match l {
        Red | Amber => true
        Green => false
    }
}

fn main() {
    print(stop(Light.Amber))
}
```
