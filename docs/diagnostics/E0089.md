# E0089: unknown escape

After a `\` a `char` literal takes one of `\n`, `\t`, `\r`, `\0`, `\\`, `\"`, `\'`, `\{`, `\}` or `\u{...}`. Any other character after the `\` is an error, reported over the `\` and that character.

## Why

An escape that Sisu does not know has no value. Guessing one would put a character in the program that the writer may not have meant, and there is no `\xNN` byte escape: a lone byte could break the UTF-8 that text must be.

## Broken

```sisu
fn main() {
    let c = '\q'
    print(c)
}
```

## Fixed

```sisu
fn main() {
    let c = '\t'
    print(c)
}
```
