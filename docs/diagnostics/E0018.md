# E0018: `mut self` on a class method

A method of a class takes `self`, never `mut self`.

## Why

An object is shared, so `self` can already write every `mut` field of the class. A `mut self` would suggest that the method could replace the object, which no method can do.

## Broken

```sisu
class Counter {
    mut n: i64

    fn bump(mut self) {
        self.n += 1
    }
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
class Counter {
    mut n: i64

    fn bump(self) {
        self.n += 1
    }
}

fn main() {
    print(1)
}
```
