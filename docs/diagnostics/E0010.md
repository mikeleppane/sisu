# E0010: character that Sisu does not use

Source text uses only the characters of Sisu's tokens. Any other character outside a comment is an error. A lone `&` or `|` is most likely a logical `&&` or `||` written with one character.

## Why

The compiler cannot tell what an unknown character was meant to be. For `&` and `|` the mistake is common enough that the report offers `&&` or `||` as an unsafe fix, which you check before you apply it.

## Broken

```sisu
fn main() {
    let ok = true & false
    print(ok)
}
```

## Fixed

```sisu
fn main() {
    let ok = true && false
    print(ok)
}
```
