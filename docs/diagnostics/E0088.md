# E0088: constant whose value would panic

Computing a constant's value follows the rules of run time. An operation that would panic at run time is an error at compile time, with the same message: "integer overflow", "division by zero" or "value does not fit in `u8`".

## Why

A constant's value is computed before the program runs, so a panic in it would happen on every run. Only what run time would compute is checked: `&&` and `||` skip their right side as at run time, and a comparison chain stops at its first false pair. Change the value so that it fits in its type, or does not divide by zero.

## Broken

```sisu
const MASK: u8 = 16 * 16

fn main() {
    print(MASK)
}
```

## Fixed

```sisu
const MASK: u8 = 16 * 15

fn main() {
    print(MASK)
}
```
