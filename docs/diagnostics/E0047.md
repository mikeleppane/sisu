# E0047: comparison of values of different types

Both sides of a comparison have one type. A `T` may stand beside a `T?`, and nothing else is compared across types. Equality and ordering comparisons between a `u8` and an `i64`, or between a `char` and an integer, report [E0032](E0032.md) instead.

## Why

A comparison of an `i64` with a `bool`, or of two different classes, can never be true. Sisu reports it instead of answering `false`.

## Broken

```sisu
fn main() {
    print(1 == true)
}
```

## Fixed

```sisu
fn main() {
    print(1 == 1)
}
```
