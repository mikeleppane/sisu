# E0053: call with the wrong number of arguments

A call passes one argument for each parameter of the function or method. The array methods `len()` and `sum()` take none and `contains(x)` takes one; a conversion `i64(...)` or `u8(...)` takes one, and so does `panic(...)`.

## Why

Sisu has no default values for parameters and no functions that take a varying number of arguments. Each parameter needs its value, and a value with no parameter has nowhere to go.

## Broken

```sisu
fn add(a: i64, b: i64) -> i64 {
    a + b
}

fn main() {
    print(add(1))
}
```

## Fixed

```sisu
fn add(a: i64, b: i64) -> i64 {
    a + b
}

fn main() {
    print(add(1, 2))
}
```
