# E0042: `u8` that is negated

A `u8` cannot be negative, so unary `-` does not apply to one.

## Why

Negating a `u8` has no `u8` result, and Sisu does not pick another type for you. Convert it to an `i64` first, and negate that.

## Broken

```sisu
fn main() {
    let b: u8 = 5
    let n = -b
    print(n)
}
```

## Fixed

```sisu
fn main() {
    let b: u8 = 5
    let n = -i64(b)
    print(n)
}
```
