# E0048: `??` on a value that is not optional

The left side of `??` is the optional that may be `None`. The right side is the value to use then.

## Why

`??` supplies a default for a missing value. A value that is not optional is never missing, so the default would never be used.

## Broken

```sisu
fn main() {
    let n = 5
    print(n ?? 0)
}
```

## Fixed

```sisu
fn main() {
    let n: i64? = 5
    print(n ?? 0)
}
```
