# E0127: only a name here

A pattern at a class, array, optional or `f64` position takes only a name, which binds the value, or `_`, which ignores it. Variants, and `None`, are not patterns there.

## Why

These types have no variants to tell apart. Bind the value and test it inside the arm; unwrap an optional with `if let`.

## Broken

```sisu
enum Slot {
    Full(i64?)
}

fn main() {
    let s = Slot.Full(None)
    let n = match s {
        Full(None) => 0
    }
    print(n)
}
```

## Fixed

```sisu
enum Slot {
    Full(i64?)
}

fn main() {
    let s = Slot.Full(None)
    let n = match s {
        Full(v) => if let x = v { x } else { 0 }
    }
    print(n)
}
```
