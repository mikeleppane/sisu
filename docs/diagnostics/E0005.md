# E0005: `[` that starts a line inside brackets

Inside `(` or `[`, a `[` cannot start a line that follows an expression.

## Why

Inside brackets a line break does not end the expression, so a `[` at the start of the next line would silently index the line above. Sisu rejects it: add a comma if the `[` starts a new element, or put it on the line of the array it indexes.

## Broken

```sisu
fn main() {
    let grid = [[1, 2], [3, 4]]
    print(grid
    [0][1])
}
```

## Fixed

```sisu
fn main() {
    let grid = [[1, 2], [3, 4]]
    print(grid[0][1])
}
```
