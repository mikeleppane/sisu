# E0098: value that cannot be interpolated

An interpolation writes an `i64`, a `u8`, an `f64`, a `bool`, a `char` or a `string` as text, as `print` does. An array, an optional, an object of a class or a `unit` value has no one text, so interpolating it is an error at the interpolated expression.

## Why

There is no one way to write an array as text: with or without brackets, separators or spaces. An optional may be `None`, which the program must decide how to show. Build the text the program needs: an array's in a `for` loop, an optional's after unwrapping it with `if let`, or with a default through `??`.

## Broken

```sisu
fn main() {
    let xs = [1, 2, 3]
    print("{xs}")
}
```

## Fixed

```sisu
fn main() {
    let xs = [1, 2, 3]
    let mut text = ""
    for x in xs {
        text += "{x} "
    }
    print(text)
}
```
