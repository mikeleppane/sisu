# E0063: field or method that does not exist

A field read or a method call must name a member of the receiver's type: a field or method of its class, or the array methods `len()`, `sum()` and `contains(x)`. A constructor's labels must name fields of its class.

When a member of the receiver's type has a similar name, the error offers it as a guess. The guess may be wrong: the name could be a member that was never written.

## Why

Sisu does not resolve a misspelled member name on its own. A misspelled name would otherwise read some other value or run some other code.

## Broken

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(x: 1)
    print(p.y)
}
```

## Fixed

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(x: 1)
    print(p.x)
}
```
