# E0063: field or method that does not exist

A field read or a method call must name a member of the receiver's type: a field or method of its class, the array methods `len()`, `sum()` and `contains(x)`, the `string` methods `len()`, `chars()`, `bytes()` and `words()`, or the methods of `f64` and `i64`, such as `x.sqrt()` and `n.max(m)`. A method of `f64` is no method of `i64`: `n.sqrt()` with an `i64` `n` is this error too. A constructor's labels must name fields of its class.

When a member of the receiver's type has a similar name, the error offers it as a guess. The guess may be wrong: the name could be a member that was never written. For `let x = 2.5` and `x.sqrtt()`, the guess is `sqrt`.

## Why

Sisu does not resolve a misspelled member name on its own. A misspelled name would otherwise read some other value or run some other code.

## Broken

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(x: 1)
    print(p.y)
}
```

## Fixed

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(x: 1)
    print(p.x)
}
```
