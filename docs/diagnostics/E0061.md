# E0061: `print` of an expression that never finishes

The argument of `print` must finish with a value. An expression such as an `if` whose branches all `return` never does, so the `print` never runs.

## Why

A `print` that can never print is a mistake: the program meant to print a value, or meant the `return` without the `print`.

## Broken

```sisu
fn report(ok: bool) {
    print(if ok { return } else { return })
}

fn main() {
    report(true)
}
```

## Fixed

```sisu
fn report(ok: bool) {
    print(if ok { 1 } else { 0 })
}

fn main() {
    report(true)
}
```
