# E0061: `print` or `eprint` of an expression that never finishes

The argument of `print` or `eprint` must finish with a value. An expression such as an `if` whose branches all `return`, or a `panic`, never does, so the call never runs.

## Why

A `print` or `eprint` that can never write is a mistake: the program meant to write a value, or meant the `return` or `panic` without the call.

## Broken

```sisu
fn report(ok: bool) {
    print(if ok { return } else { return })
}

fn main() {
    report(true)
}
```

## Fixed

```sisu
fn report(ok: bool) {
    print(if ok { 1 } else { 0 })
}

fn main() {
    report(true)
}
```
