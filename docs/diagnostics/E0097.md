# E0097: comment inside an interpolation

A `//` comment cannot appear inside an interpolation. The error is reported at the `//`. Write the comment on a line of its own, or after the string.

## Why

A comment runs to the end of its line, so it would take the closing `}` and the rest of the string with it. The compiler offers no fix, since it cannot tell where the comment should go.

## Broken

```sisu
fn main() {
    let total = 3
    print("{total // the sum}")
}
```

## Fixed

```sisu
fn main() {
    let total = 3
    // the sum
    print("{total}")
}
```
