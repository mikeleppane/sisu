# E0045: `is` used to test for `None`

`is` tests identity: whether two references refer to the same object. `None` is no object, so `is` does not apply to it.

## Why

Testing for `None` is a comparison of values, written with `==`.

## Broken

```sisu
class Node {
    next: Node?
}

fn main() {
    let n = Node(next: None)
    print(n.next is None)
}
```

## Fixed

```sisu
class Node {
    next: Node?
}

fn main() {
    let n = Node(next: None)
    print(n.next == None)
}
```
