# E0011: token where something else belongs

The parser expected one thing and found another. The message names both, with the thing found written as it appears in the source, or as `end of line` or `end of file`.

## Why

Sisu's syntax is small, so the expected thing is nearly always one specific token or kind of name. The message reads as a sentence, such as "expected a binding name, found `=`".

## Broken

```sisu
fn main() {
    let = 1
    print(1)
}
```

## Fixed

```sisu
fn main() {
    let x = 1
    print(x)
}
```
