# E0023: range outside `for`

A range such as `0..n` can only be the source of a `for` loop.

## Why

A range is not a value in Sisu. It only describes what a `for` loop counts through, so it cannot be stored, passed or returned.

## Broken

```sisu
fn main() {
    let r = 0..3
    print(1)
}
```

## Fixed

```sisu
fn main() {
    for i in 0..3 {
        print(i)
    }
}
```
