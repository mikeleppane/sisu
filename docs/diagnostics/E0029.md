# E0029: `main` with parameters or a return type

`main` takes no parameters and returns no value.

## Why

Nothing calls `main` with arguments or reads what it returns. The program ends when `main` does.

## Broken

```sisu
fn main(n: i64) {
    print(n)
}
```

## Fixed

```sisu
fn main() {
    print(1)
}
```
