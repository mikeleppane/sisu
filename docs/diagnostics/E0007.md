# E0007: closing bracket that does not match

A `)`, `]` or `}` must close the innermost bracket that is still open, and it must be the matching one.

## Why

A closing bracket that does not match shifts the meaning of everything after it. When another bracket is open instead, the error points at it too.

## Broken

```sisu
fn main() {
    print(1)
}
}
```

## Fixed

```sisu
fn main() {
    print(1)
}
```
