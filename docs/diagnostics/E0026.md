# E0026: name taken by a built-in

The names `i64`, `u8`, `f64`, `bool`, `char` and `string` belong to the built-in types. A class, a function or a constant cannot take one. A variant cannot be called `None`, which is a keyword.

## Why

A type name stands where a type is expected, and `u8(...)`, `i64(...)`, `f64(...)` and `char(...)` convert a value. A class, a function or a constant with one of these names would make the same word mean two things.

## Broken

```sisu
class u8 {
    n: i64
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
class Byte {
    n: i64
}

fn main() {
    print(1)
}
```
