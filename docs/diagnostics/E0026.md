# E0026: item named like a built-in type

The names `i64`, `u8`, `bool`, `char` and `string` belong to the built-in types. A class, a function or a constant cannot take one.

## Why

A type name stands where a type is expected, and `u8(...)`, `i64(...)` and `char(...)` convert a value. A class, a function or a constant with one of these names would make the same word mean two things.

## Broken

```sisu
class u8 {
    n: i64
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
class Byte {
    n: i64
}

fn main() {
    print(1)
}
```
