# E0056: constructor without every field

A constructor names every field of its class, in declaration order: `Point(x: 1, y: 2)`.

## Why

Sisu has no default values for fields. Every field of a new object needs a value, so a constructor that leaves one out cannot build it.

## Broken

```sisu
class Point {
    x: i64
    y: i64
}

fn main() {
    let p = Point(x: 1)
    print(p.x)
}
```

## Fixed

```sisu
class Point {
    x: i64
    y: i64
}

fn main() {
    let p = Point(x: 1, y: 2)
    print(p.x)
}
```
