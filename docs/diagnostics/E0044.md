# E0044: comparison of a value that is never `None` with `None`

Only an optional can be `None`. Comparing a value of another type with `None` has a fixed answer, so Sisu reports it.

## Why

A comparison that can only come out one way is a sign that the type is not what the writer thinks. Either the value should be optional, or the comparison should go.

## Broken

```sisu
fn main() {
    let n = 5
    print(n == None)
}
```

## Fixed

```sisu
fn main() {
    let n: i64? = 5
    print(n == None)
}
```
