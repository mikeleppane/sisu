# E0085: constant of a type that cannot be folded

A constant is an `i64`, a `u8` or a `bool`.

## Why

The compiler computes a constant's value and puts it in place of each use. That works for a value that fits in a literal. An array, an optional or an object is made at run time, and a copy at each use would be a new one. Use a `let` in the function that needs the value, or a function that returns it.

## Broken

```sisu
const PRIMES: [i64] = [2, 3, 5]

fn main() {
    print(PRIMES[0])
}
```

## Fixed

```sisu
fn main() {
    let primes = [2, 3, 5]
    print(primes[0])
}
```
