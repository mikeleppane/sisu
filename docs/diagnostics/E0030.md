# E0030: type that does not exist

A type is `i64`, `u8`, `f64`, `bool`, `char`, `string`, a class, or an array of a type such as `[i64]`, and any of these may be followed by `?`. Any other name is not a type.

When a class or built-in type has a similar name, the error offers it as a guess. The guess may be wrong: the name could be a class that was never written.

## Why

Sisu checks every value against its type, so each type a program names must be one the program can see.

## Broken

```sisu
fn main() {
    let count: Number = 3
    print(count)
}
```

## Fixed

```sisu
fn main() {
    let count: i64 = 3
    print(count)
}
```
