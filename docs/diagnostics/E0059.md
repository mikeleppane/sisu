# E0059: `print` of something it cannot print

`print` takes exactly one argument, an `i64`, a `u8`, a `bool`, a `char` or a `string`, and prints it on its own line.

## Why

An object, an optional or a call that returns nothing has no one way to be printed. A program prints the fields or the payload it means, one `print` each.

## Broken

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(x: 1)
    print(p)
}
```

## Fixed

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(x: 1)
    print(p.x)
}
```
