# E0035: `for` over something that is not an array or a range

`for` takes an array, or a range such as `0..n`.

## Why

A `for` visits one element after another. A single number or a `bool` has no elements to visit.

## Broken

```sisu
fn main() {
    for n in 5 {
        print(n)
    }
}
```

## Fixed

```sisu
fn main() {
    for n in 0..5 {
        print(n)
    }
}
```
