# W0006: unreachable arm

An arm of a `match` that no value reaches, because the arms above it already match every value it matches. When one arm above takes all of them, a label points at it. The program still builds.

## Why

Arms are tried in order and the first that matches wins, so an arm below others that match the same values never runs. That is usually a mistake: an arm placed below a catch-all, or a pattern meant to be narrower. The check sees what the arms above match together, so `Add(_, _)` is unreachable after arms for `Add(Num(_), _)`, `Add(Add(_, _), _)` and `Add(Mul(_, _), _)`, though no one of them covers it.

The unsafe fix removes the arm. It is unsafe because the arm may be the one you meant, and the arm above it the mistake.

## Broken

```sisu
enum Light {
    Red
    Green
}

fn go(l: Light) -> bool {
    match l {
        _ => false
        Green => true
    }
}

fn main() {
    print(go(Light.Green))
}
```

## Fixed

```sisu
enum Light {
    Red
    Green
}

fn go(l: Light) -> bool {
    match l {
        Green => true
        _ => false
    }
}

fn main() {
    print(go(Light.Green))
}
```
