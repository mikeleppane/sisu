# E0072: source that is not valid UTF-8

A source file must be text in UTF-8. The error points at the first byte that is not.

## Why

Sisu reads every source file as UTF-8, so that a column and a string mean the same thing in every editor. A file saved in another encoding, such as Latin-1, stores a character like `é` as a byte that UTF-8 does not allow there.

## Broken

The file below, saved in Latin-1:

```sisu
fn main() {
    // café
    print(1)
}
```

## Fixed

The same file, saved in UTF-8:

```sisu
fn main() {
    // café
    print(1)
}
```
