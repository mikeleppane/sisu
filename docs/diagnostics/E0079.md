# E0079: `_` used as a value

`_` is no value. It is valid only after `let` and `for`, where it binds nothing. Reading it, as in `print(_)`, or assigning to it, as in `_ = make()`, is an error.

## Why

A name that is `_` holds nothing, so there is nothing to read or to assign to. To evaluate an expression and drop its value, bind it with `let _`. When the statement is a plain `_ = e`, the fix writes `let ` in front of it. For `_ += e` and the like there is no fix, because `let _ += e` is not a statement.

## Broken

```sisu
fn make() -> i64 {
    1
}

fn main() {
    _ = make()
}
```

## Fixed

```sisu
fn make() -> i64 {
    1
}

fn main() {
    let _ = make()
}
```
