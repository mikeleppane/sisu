# E0039: parameter name used twice

Each parameter of a function or method needs a name of its own. A `let` or
`let mut` may reuse a name, a parameter's included: the new binding shadows the
old one from its declaration onwards.

## Why

A call passes its arguments by position, but the body reads them by name. With
two parameters named `a`, a read of `a` could mean either argument.

## Broken

```sisu
fn add(a: i64, a: i64) -> i64 {
    a + a
}

fn main() {
    print(add(1, 2))
}
```

## Fixed

```sisu
fn add(a: i64, b: i64) -> i64 {
    a + b
}

fn main() {
    print(add(1, 2))
}
```
