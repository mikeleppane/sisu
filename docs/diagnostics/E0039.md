# E0039: name declared twice in one scope

A block declares each binding name once. The parameters of a function share one scope just outside its body, so two parameters cannot share a name, but a `let` in the body may reuse a parameter's name. A `for`, `if let` or `while let` variable belongs to the block it opens, so a `let` in that block cannot reuse it.

## Why

A second `let` of the same name in one block would hide the first from the reader, and the first value could never be read again. A name in an inner block may reuse an outer name, because the outer one is still there when the block ends.

## Broken

```sisu
fn main() {
    let total = 1
    let total = 2
    print(total)
}
```

## Fixed

```sisu
fn main() {
    let total = 1
    let next = 2
    print(total + next)
}
```
