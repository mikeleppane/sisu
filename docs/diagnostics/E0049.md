# E0049: `?.` on a value that is not optional

`?.` reads a field or calls a method of an optional, and is `None` when the optional is. Its receiver must be an optional.

## Why

A receiver that is not optional is never `None`, so a plain `.` says the same, and its result is not made optional.

## Broken

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(x: 1)
    let x = p?.x
    print(x)
}
```

## Fixed

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(x: 1)
    let x = p.x
    print(x)
}
```
