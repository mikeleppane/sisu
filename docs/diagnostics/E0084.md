# E0084: `const` inside a function

A constant is declared at the top level, beside `fn` and `class`. Inside a function, a value that does not change is a `let`.

## Why

A `const` names one value for the whole program, and its value is known at compile time. A `let` in a function already gives a name that cannot change, and its value may come from anything in scope. Replacing `const` with `let` is always right.

## Broken

```sisu
fn main() {
    const limit = 100
    print(limit)
}
```

## Fixed

```sisu
fn main() {
    let limit = 100
    print(limit)
}
```
