# E0110: format spec width or precision above its limit

A width in a format spec is at most 1000, and a precision at most 30: `{x:1000.30}` is the largest spec. The error points at the spec, from its `:`, and names the limit it breaks.

## Why

The limits bound the text that one formatted part can make, so a program cannot ask for a megabyte of padding by mistake, and the compiled code can format each part into a buffer of fixed size. A width above 1000 or a precision above 30 is almost always a typo. There is no fix, since the value you meant is not known.

## Broken

```sisu
fn main() {
    let x = 2.5
    print("{x:.31}")
}
```

## Fixed

```sisu
fn main() {
    let x = 2.5
    print("{x:.3}")
}
```
