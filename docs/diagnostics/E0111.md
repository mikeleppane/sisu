# E0111: precision on a value that is not an `f64`

A precision in a format spec, `{x:.2}`, sets the number of decimals of an `f64`. Any other value has no decimals, so a precision on it is an error. The error points at the spec, from its `:`.

## Why

An `i64`, a `u8`, a `bool`, a `char` and a `string` have no decimals to round. Rust takes a precision on a string to cut it short, and Python rejects it on an integer; Sisu gives it the one meaning. For an `i64`, the fix converts the value with `f64(...)`, which never fails; beyond 2^53 it rounds to the nearest `f64`. Any other type gets no fix: remove the precision, or convert the value yourself.

## Broken

```sisu
fn main() {
    let n = 7
    print("{n:.2}")
}
```

## Fixed

```sisu
fn main() {
    let n = 7
    print("{f64(n):.2}")
}
```
