# E0099: `todo` written another way

`todo` is a keyword, not a function or a macro. It is written bare, `todo`, or with one message in parentheses, `todo("why")`. Rust's `todo!` and `todo!("why")`, and the empty call `todo()`, are errors at the first extra token.

## Why

Sisu has no macros, so the `!` of Rust's `todo!` means nothing here, and `todo()` with nothing in the parentheses says no more than bare `todo`. Each form has one meaning, so the fix is safe: it removes the `!`, the `()`, or both, which leaves `todo` or `todo("why")`. When a word follows with no space, as in `todo!x`, the removal would join it to `todo`, so the fix is unsafe.

## Broken

```sisu
fn area(width: i64, height: i64) -> i64 {
    todo!("multiply")
}

fn main() {
    print(area(2, 3))
}
```

## Fixed

```sisu
fn area(width: i64, height: i64) -> i64 {
    todo("multiply")
}

fn main() {
    print(area(2, 3))
}
```
