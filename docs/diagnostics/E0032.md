# E0032: value of the wrong type

A value must have the type its position expects: the declared type of a `let`, the parameter of a function, the return type of a function, the operand of an operator.

## Why

Sisu does not convert between number types by itself. A `u8`, a `char` and an `i64` are different types even when the number would fit, so a program says where one becomes another with `u8(...)`, `i64(...)` or `char(...)`. A `u8` and a `char` convert through `i64`: `char(i64(b))`. A conversion takes one type: `i64(...)` takes a `u8` or a `char`, and `u8(...)` and `char(...)` take an `i64`.

A `panic` message is a `string`. An `i64`, `u8`, `bool` or `char` written on one line becomes one with interpolation: `panic(n)` is `panic("{n}")`.

## Broken

```sisu
fn main() {
    let n: i64 = 5
    let b: u8 = n
    print(b)
}
```

## Fixed

```sisu
fn main() {
    let n: i64 = 5
    let b: u8 = u8(n)
    print(b)
}
```
