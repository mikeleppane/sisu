# E0032: value of the wrong type

A value must have the type its position expects: the declared type of a `let`, the parameter of a function, the return type of a function, the operand of an operator.

## Why

Sisu does not convert between number types by itself. A `u8` and an `i64` are different types even when the number would fit, so a program says where one becomes the other with `u8(...)` or `i64(...)`.

## Broken

```sisu
fn main() {
    let n: i64 = 5
    let b: u8 = n
    print(b)
}
```

## Fixed

```sisu
fn main() {
    let n: i64 = 5
    let b: u8 = u8(n)
    print(b)
}
```
