# E0013: `var` instead of `let mut`

Sisu has no `var`. A variable that can change is declared with `let mut`, and a field that can change is marked `mut`.

## Why

`mut` marks everything that can change ([ADR 0011](../adr/0011-let-mut-marks-what-can-change.md)), so there is one keyword for it, in bindings and in fields.

## Broken

```sisu
fn main() {
    var count = 0
    count += 1
    print(count)
}
```

## Fixed

```sisu
fn main() {
    let mut count = 0
    count += 1
    print(count)
}
```
