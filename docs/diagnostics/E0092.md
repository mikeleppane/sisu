# E0092: `char` literal that is not one code point

A `char` literal holds exactly one code point. `''` holds none, and `'ab'` holds two. An `e` followed by a combining accent between the quotes is two code points too, however it looks on the screen. Text is a string, written in double quotes: `"ab"`.

## Why

A `char` is one Unicode scalar value, not what a reader sees as one character. Single quotes around text are a string in some languages, so the report offers double quotes as a guess, unless the text holds `"`, `{` or `}`, which a string reads differently.

## Broken

```sisu
fn main() {
    let c = 'ab'
    print(c)
}
```

## Fixed

```sisu
fn main() {
    let c = 'a'
    print(c)
}
```
