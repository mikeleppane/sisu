# E0103: float literal out of range for `f64`

A float literal must round to a finite `f64`, which holds magnitudes up to about 1.8e308. `1e400` rounds to infinity and is an error.

## Why

A literal is rounded to the nearest `f64`, and no `f64` is near `1e400`. Silently turning it into infinity would hide a typo, so the literal is an error. A literal below the smallest `f64`, such as `1e-400`, rounds to zero and is not an error. The compiler does not invent a value, so there is no fix.

## Broken

```sisu
fn main() {
    let x = 1e400
    print(x)
}
```

## Fixed

```sisu
fn main() {
    let x = 1e300
    print(x)
}
```
