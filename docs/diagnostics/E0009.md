# E0009: integer literal too large for `i64`

An integer literal must fit in an `i64`, which holds values up to 9223372036854775807.

## Why

Sisu has no integer type that is wider than `i64`, so a literal beyond its range cannot hold the value it names. The one exception is `-9223372036854775808`, the smallest `i64`: a `-` directly before the literal makes one negative literal of them.

## Broken

```sisu
fn main() {
    let n = 9223372036854775808
    print(n)
}
```

## Fixed

```sisu
fn main() {
    let n = 9223372036854775807
    print(n)
}
```
