# E0134: interpolation in a string pattern

A string pattern matches one string as written, so it takes no interpolation: `"{x}"` is not a pattern.

## Why

A pattern compares with values known when the program compiles. An interpolation is computed when the program runs, and in some languages a pattern like `"{x}"` would bind `x` to part of the string instead. Bind the string and compare it in a guard.

## Broken

```sisu
fn greet(s: string, name: string) -> bool {
    match s {
        "hello {name}" => true
        _ => false
    }
}

fn main() {
    print(greet("hello Ada", "Ada"))
}
```

## Fixed

```sisu
fn greet(s: string, name: string) -> bool {
    match s {
        t if t == "hello {name}" => true
        _ => false
    }
}

fn main() {
    print(greet("hello Ada", "Ada"))
}
```
