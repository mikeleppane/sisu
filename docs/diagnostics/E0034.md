# E0034: name defined twice

Functions, classes and constants share one namespace, and so do the fields and methods of a class. Each name is defined once in its namespace. The prelude functions `print` and `panic` are built in, so no function, class or constant can take their names.

## Why

A call or a type that names a duplicate could mean either definition. Sisu keeps the first and reports the second.

## Broken

```sisu
fn double(n: i64) -> i64 {
    n * 2
}

fn double(n: i64) -> i64 {
    n + n
}

fn main() {
    print(double(2))
}
```

## Fixed

```sisu
fn double(n: i64) -> i64 {
    n * 2
}

fn main() {
    print(double(2))
}
```
