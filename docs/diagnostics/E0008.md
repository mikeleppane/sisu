# E0008: `_` outside digits

A `_` in an integer literal must stand between two digits, as in `1_000_000`.

## Why

A `_` only groups digits so that long numbers are easy to read. A doubled or trailing `_` groups nothing, so it is more likely a typo than a choice.

## Broken

```sisu
fn main() {
    let n = 1__000
    print(n)
}
```

## Fixed

```sisu
fn main() {
    let n = 1_000
    print(n)
}
```
