# E0078: `mut` on `_`

`let _ = e` evaluates `e` and drops the value at once. It binds no name, so it cannot be `mut`.

## Why

`mut` lets a name be assigned again, and `_` is no name: nothing can ever assign to it. The fix deletes the `mut`, and nothing else.

## Broken

```sisu
fn make() -> i64 {
    1
}

fn main() {
    let mut _ = make()
}
```

## Fixed

```sisu
fn make() -> i64 {
    1
}

fn main() {
    let _ = make()
}
```
