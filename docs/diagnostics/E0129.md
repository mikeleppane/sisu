# E0129: name bound twice in one pattern

Each name in a pattern binds one field, so a name appears at most once in a pattern.

## Why

In some languages `Add(x, x)` matches only when both fields are equal; in Sisu a pattern never compares two fields. Bind two names and compare them inside the arm.

## Broken

```sisu
enum Expr {
    Add(i64, i64)
}

fn same(e: Expr) -> bool {
    match e {
        Add(x, x) => true
    }
}

fn main() {
    print(same(Expr.Add(1, 1)))
}
```

## Fixed

```sisu
enum Expr {
    Add(i64, i64)
}

fn same(e: Expr) -> bool {
    match e {
        Add(x, y) => x == y
    }
}

fn main() {
    print(same(Expr.Add(1, 1)))
}
```
