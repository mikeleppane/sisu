# E0070: array method called as a function

`len()`, `sum()` and `contains(x)` are methods of arrays: `xs.len()`, not `len(xs)`. When no function of that name exists and the first argument is an array with that method, the error offers the method call.

The fix is certain when the method call takes the remaining arguments as written. Otherwise it is a guess, and the arguments still need fixing: `len(xs, 1)` becomes `xs.len(1)`, and `len()` takes no arguments. It is also a guess when the rewrite would delete a comment inside the call.

## Why

These operations are array methods, and Sisu has no built-in functions of the same names. Each belongs to the array, so it is called on the array. You can still define a function of your own that takes an array, even one named `len`, and call it as a function.

## Broken

```sisu
fn main() {
    let xs = [1, 2, 3]
    print(len(xs))
}
```

## Fixed

```sisu
fn main() {
    let xs = [1, 2, 3]
    print(xs.len())
}
```
