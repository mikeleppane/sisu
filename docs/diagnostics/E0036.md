# E0036: `return` without a value

A function with a return type returns a value of that type, so each `return` in it carries one.

## Why

The caller waits for a value of the declared type. A bare `return` would leave it with nothing.

## Broken

```sisu
fn five() -> i64 {
    return
}

fn main() {
    print(five())
}
```

## Fixed

```sisu
fn five() -> i64 {
    return 5
}

fn main() {
    print(five())
}
```
