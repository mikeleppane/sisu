# E0040: integer literal too large for `u8`

A number written in a place that expects a `u8` must be between 0 and 255.

## Why

A `u8` is one byte. A literal that does not fit would have to lose bits to become one, and Sisu does not do that silently.

## Broken

```sisu
fn main() {
    let b: u8 = 300
    print(b)
}
```

## Fixed

```sisu
fn main() {
    let b: u8 = 200
    print(b)
}
```
