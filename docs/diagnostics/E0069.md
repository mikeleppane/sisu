# E0069: `sum` of an array that is not `[i64]`

`sum()` adds the elements of an array of `i64`.

## Why

Only `i64` elements have a sum of the same type. Sisu does not convert a `u8` or a `bool` to a number by itself.

## Broken

```sisu
fn main() {
    let flags = [true, false]
    print(flags.sum())
}
```

## Fixed

```sisu
fn main() {
    let flags = [true, false]
    let mut count = 0
    for flag in flags {
        if flag {
            count += 1
        }
    }
    print(count)
}
```
