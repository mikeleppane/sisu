# E0055: labeled argument in a call

Only a constructor takes labels on its arguments: `Point(x: 1)`. A function call, a method call and `print` take plain arguments in parameter order.

## Why

Labels on the arguments of function calls come in milestone 10. Until then, a label there is reported, not ignored, so a program does not rely on a meaning that has not arrived.

## Broken

```sisu
fn double(n: i64) -> i64 {
    n * 2
}

fn main() {
    print(double(n: 2))
}
```

## Fixed

```sisu
fn double(n: i64) -> i64 {
    n * 2
}

fn main() {
    print(double(2))
}
```
