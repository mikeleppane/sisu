# E0076: base prefix without digits

A `0x`, `0b` or `0o` must be followed by at least one digit of its base.

## Why

The prefix only names the base. Without a digit there is no number to read, so it is more likely an unfinished literal than a choice.

## Broken

```sisu
fn main() {
    let n = 0x
    print(n)
}
```

## Fixed

```sisu
fn main() {
    let n = 0xFF
    print(n)
}
```
