# E0081: block that stands alone as a statement

A `{ ... }` block is an expression. It belongs where a value does, as in `let x = { ... }`. A statement cannot start with `{`.

## Why

A block's value is its last expression. As a statement that value would go nowhere, and a scope with no value has no use of its own. Put the block where its value is wanted.

## Broken

```sisu
fn main() {
    {
        let a = 1
        print(a + 2)
    }
}
```

## Fixed

```sisu
fn main() {
    let total = {
        let a = 1
        a + 2
    }
    print(total)
}
```
