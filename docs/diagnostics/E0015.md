# E0015: field, variant or arm list on one line

Each field of a class, each variant of an enum and each arm of a `match` stands on its own line, with no comma between them.

## Why

A line break separates the members of a class or an enum and the arms of a `match`, as it separates statements. Fields, variants or arms written with commas would be a second way to say the same thing. The fix removes the comma and breaks the line: it deletes a comma that ends its line, and replaces any other with a line break and the line's indentation.

## Broken

```sisu
class Point {
    x: i64, y: i64
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
class Point {
    x: i64
    y: i64
}

fn main() {
    print(1)
}
```
