# E0015: field list on one line

Each field of a class stands on its own line, with no comma between fields.

## Why

A line break separates the members of a class, as it separates statements. Fields written with commas would be a second way to say the same thing.

## Broken

```sisu
class Point {
    x: i64, y: i64
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
class Point {
    x: i64
    y: i64
}

fn main() {
    print(1)
}
```
