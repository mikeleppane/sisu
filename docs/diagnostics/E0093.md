# E0093: `char` literal that is not closed

A `char` literal ends with a `'` on the line it starts on. A line break or the end of the file before that `'` is an error, reported at the opening `'`.

## Why

The compiler cannot tell where the literal should have ended, so it offers no fix.

## Broken

```sisu
fn main() {
    let c = 'a
    print(c)
}
```

## Fixed

```sisu
fn main() {
    let c = 'a'
    print(c)
}
```
