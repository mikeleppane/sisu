# E0025: comparison chain that turns around

A chain of `<` and `<=`, or of `>` and `>=`, goes in one direction. Mixing the two directions is an error.

## Why

`a < b > c` compares `a` with `b` and `b` with `c`, but says nothing about `a` and `c`, which makes a chain hard to read. Sisu allows only the chains that read like an ordering, such as `a < b <= c`.

## Broken

```sisu
fn main() {
    let a = 1
    let b = 2
    let c = 1
    print(a < b > c)
}
```

## Fixed

```sisu
fn main() {
    let a = 1
    let b = 2
    let c = 1
    print(a < b && b > c)
}
```
