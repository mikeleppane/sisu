# E0068: index of something that is not an array

Only an array can be indexed: `xs[i]`.

## Why

A number, a `bool` or an object holds no elements, so there is nothing for an index to select.

## Broken

```sisu
fn main() {
    let n = 5
    print(n[0])
}
```

## Fixed

```sisu
fn main() {
    let xs = [5]
    print(xs[0])
}
```
