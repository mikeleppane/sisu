# E0077: digit outside the literal's base

A hexadecimal literal uses the digits `0-9`, `a-f` and `A-F`, a binary literal uses `0` and `1`, and an octal literal uses `0-7`. Any other letter or digit after the prefix is an error, reported at that character.

## Why

A digit that the base does not have has no value there. `0b102` would be a typo for a binary number, or a decimal number written with the wrong prefix, and the compiler cannot tell which.

## Broken

```sisu
fn main() {
    let n = 0xFG
    print(n)
}
```

## Fixed

```sisu
fn main() {
    let n = 0xFF
    print(n)
}
```
