# E0037: `return` with a value in a function that returns none

A function without a return type returns no value, so its `return` stands alone.

## Why

The caller of such a function has no value to receive. Declare a return type, such as `-> i64`, to return one.

## Broken

```sisu
fn show() {
    return 5
}

fn main() {
    show()
}
```

## Fixed

```sisu
fn show() {
    print(5)
    return
}

fn main() {
    show()
}
```
