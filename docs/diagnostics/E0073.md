# E0073: assignment to `self`

A method cannot assign a new object to `self`.

## Why

An object is shared: every variable that holds it refers to the same object. Assigning to `self` would only change what the method calls `self`, not the object the caller has. To change the object, assign to its `mut` fields.

## Broken

```sisu
class Point {
    mut x: i64

    fn reset(self) {
        self = Point(x: 0)
    }
}

fn main() {
    let p = Point(x: 1)
    p.reset()
    print(p.x)
}
```

## Fixed

```sisu
class Point {
    mut x: i64

    fn reset(self) {
        self.x = 0
    }
}

fn main() {
    let p = Point(x: 1)
    p.reset()
    print(p.x)
}
```
