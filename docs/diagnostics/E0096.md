# E0096: empty interpolation

An interpolation holds an expression. `{}` in a string literal, braces with only spaces between them, and `{:>8}`, a format spec with no expression before it, hold none. The error covers the braces.

## Why

The compiler cannot tell whether an expression is missing or the braces were meant as text. The fix writes `\{\}`, the literal braces, which is a guess: you may have meant to write an expression there.

## Broken

```sisu
fn main() {
    print("{}")
}
```

## Fixed

```sisu
fn main() {
    print("\{\}")
}
```
