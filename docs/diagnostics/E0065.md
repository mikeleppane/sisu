# E0065: constructor argument without a label

Each argument of a constructor is labeled with the field it sets: `Point(x: 1)`.

## Why

The label says which field gets which value, so a constructor reads the same however many fields its class has, and swapping two values of one type cannot go unnoticed.

## Broken

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(1)
    print(p.x)
}
```

## Fixed

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(x: 1)
    print(p.x)
}
```
