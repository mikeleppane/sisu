# E0024: chained `==`, `!=` or `is`

`==`, `!=` and `is` do not chain: a second one after the first in the same expression is an error.

## Why

`a == b == c` reads as "all equal" in some languages and as a comparison of a boolean in others. Sisu allows neither. Join separate comparisons with `&&`.

## Broken

```sisu
fn main() {
    let a = 1
    let b = 1
    let c = 1
    print(a == b == c)
}
```

## Fixed

```sisu
fn main() {
    let a = 1
    let b = 1
    let c = 1
    print(a == b && b == c)
}
```
