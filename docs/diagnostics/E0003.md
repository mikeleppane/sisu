# E0003: bracket that is never closed

Every `(`, `[` and `{` needs its closing bracket before the end of the file. The error points at the innermost bracket that is still open.

## Why

A missing closing bracket changes what every later line means, so the compiler stops at the end of the file and names the bracket that never closed.

## Broken

```sisu
fn main() {
    print(1)
```

## Fixed

```sisu
fn main() {
    print(1)
}
```
