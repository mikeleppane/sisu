# E0118: unknown variant

`Enum.Name` builds the variant `Name` of the enum, so the enum must declare a variant of that name.

## Why

An enum lists every variant it has; there are no others to build. When a variant's name is close to the one written, the error suggests it, but as an unsafe fix: the closest name is not always the one you meant.

## Broken

```sisu
enum Expr {
    Num(i64)
}

fn main() {
    let _ = Expr.Nmu(2)
}
```

## Fixed

```sisu
enum Expr {
    Num(i64)
}

fn main() {
    let _ = Expr.Num(2)
}
```
