# E0060: `print` or `eprint` of an array

`print` and `eprint` write one `i64`, `u8`, `bool`, `char` or `string`. An array, or an optional array, is many values.

## Why

There is no one way to print an array: on one line or many, with or without separators. A loop prints each element the way the program needs.

## Broken

```sisu
fn main() {
    let xs = [1, 2, 3]
    print(xs)
}
```

## Fixed

```sisu
fn main() {
    let xs = [1, 2, 3]
    for x in xs {
        print(x)
    }
}
```
