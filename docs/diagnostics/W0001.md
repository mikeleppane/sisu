# W0001: unreachable code

A statement that comes after one that never finishes, such as `return`,
`break`, `continue`, or an `if` whose branches all return, can never run. The
warning points at the first such statement in the block.

## Why

Code that cannot run is almost always a mistake: a `return` written too
early, or a statement meant to come before a `break`. Sisu warns where the
source tells its reader something false, as it does for a `let mut` that never
changes ([ADR 0011](../adr/0011-let-mut-marks-what-can-change.md)).

## Broken

```sisu
fn main() {
    print(1)
    return
    print(2)
}
```

## Fixed

```sisu
fn main() {
    print(1)
    print(2)
}
```
