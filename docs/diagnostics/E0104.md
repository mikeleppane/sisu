# E0104: integer literal not exactly an `f64`

An integer literal in a place that expects an `f64` must be a value the `f64` holds exactly. Every integer up to 2^53 (9007199254740992) is one; above that, only some are.

## Why

An `f64` has 53 bits of precision, so above 2^53 it skips integers. `9007199254740993` would become `9007199254740992.0`, a different number, and Sisu does not change a number silently. The fix writes the value the `f64` holds, as a float literal, so the program says what it computes.

## Broken

```sisu
fn main() {
    let x: f64 = 9007199254740993
    print(x)
}
```

## Fixed

```sisu
fn main() {
    let x: f64 = 9007199254740992.0
    print(x)
}
```
