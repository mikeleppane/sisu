# E0051: `if let` or `while let` on a value that is not optional

`if let` and `while let` unwrap an optional: they run their block with the value inside, when there is one.

## Why

A value that is not optional is always there, so there is nothing to test. Use the value itself.

## Broken

```sisu
fn main() {
    let n = 5
    if let x = n {
        print(x)
    }
}
```

## Fixed

```sisu
fn main() {
    let n: i64? = 5
    if let x = n {
        print(x)
    }
}
```
